# 直播大纲制作指南

本指南用于起草直播大纲前的结构判断。它与 `recent_30_outline_patterns.md` 分工如下：本文件回答“不同选题怎么搭骨架、常用内容如何复用、单页怎么写”；近30期基准回答“最近已定稿大纲实际采用什么语气、密度和节奏”。两份文件都要读。

## 一、固定工作原则

1. 先确定观众要解决的核心问题，用一句话写出本期结论。
2. 先搭“问题—判断—证据—行动”的最短闭环，再拆成页面。
3. 初稿只写参考资料和逐页大纲；主要思路、总结页、标题、介绍文案留到用户修改并确认图片后填写。
4. 同时检索公募直播、私募/高净值直播、对外演讲三个历史PPT库，并实际打开候选页面。
5. 每页标明直接复用、修改后复用、组合复用或新做；复用页必须附整页截图。
6. 一页只讲一个意思，页标题优先使用短问句或明确结论句。
7. 数据没有核实就写待更新或待复核，不凭记忆补数字。
8. 结尾必须回答投资者具体怎么做，并落到低估买入、正常估值持有、高估止盈及星级/估值表。

## 二、九类选题结构

### 1. 热点事件类

发生了什么 → 为什么发生 → 影响哪些市场或资产 → 历史上有没有类似阶段 → 后续关注什么 → 投资者怎么办。

- 开头用最新事实建立背景，不把全场做成新闻复述。
- 原因只保留能推进结论的2—3个，每个原因尽量有数据或历史案例支撑。
- 热点型初稿通常控制在15—20页；第二个历史案例不能推进结论时删除。

### 2. 市场判断类

当前市场处于什么位置 → 支撑判断的基本面、资金面、情绪面 → 和历史阶段比较 → 哪些信号意味着阶段变化 → 不同资金状态怎么应对。

- 先摆估值、盈利、资金和情绪证据，再下牛熊或阶段判断。
- 不以单一指标预测市场，强调多个因素综合判断。

### 3. 阶段复盘类

区间表现总览 → 哪些品种领先或落后 → 主要驱动因素 → 原判断是否兑现 → 有哪些经验 → 下一阶段如何安排。

- 统一收益区间、频率、价格/全收益口径和比较基准。
- 复盘重点是验证方法，不是罗列涨跌榜。

### 4. 指数或品种介绍类

为什么现在讲 → 是什么/规则 → 与相近品种的区别 → 行业与成分股 → 长期表现和波动 → 估值 → 对应基金 → 风险 → 如何投资。

- 不只回答“好不好”，还要回答“适合谁、当前贵不贵、怎么买、有什么风险”。
- 面向小白时先讲上位概念和类型区别；同一品种按“是什么/解决什么问题＋购买重点看什么”形成双页闭环。

### 5. 行业主题类

行业做什么 → 产业链与商业模式 → 需求和供给驱动 → 盈利周期 → 指数和成分股 → 历史表现 → 当前估值 → 风险 → 如何投资。

- 行业故事必须落到盈利和估值，不能只讲政策或空间。
- 周期行业说明所处周期位置；成长行业说明盈利兑现和估值消化。

### 6. 操作方法类

投资者痛点 → 方法是什么 → 适用条件 → 操作步骤 → 历史案例或数据验证 → 常见错误 → 风险和限制 → 如何执行。

- 操作路径尽量压缩成2—3步。
- 功能或工具必须写清在哪里看、多久更新、怎么使用。

### 7. 财报与定期更新类

披露内容/规则是什么 → 为什么值得看 → 本次数据总览 → 分类别拆解 → 与上期比较 → 结论和投资影响。

- 优先复用上一轮同选题PPT，只更新数据、结论和新增品种。
- “景气、复苏、低迷”等定性标题必须等待新数据后重新判断。

### 8. 组合运作类

本期发生了什么 → 组合定位和目标 → 调整逻辑 → 调整前后对比 → 风险控制 → 适用人群和持有方式 → 常见问题。

- 高净值场次强调策略，不公开不该公开的具体组合信息。
- 月薪宝表述为“主要投资固收+基金”，不说“属于固收+”。
- 产品状态、申购状态和规模必须带日期并在发布前复核。

### 9. 制式话题与人生规划类

目标和需求 → 钱从哪里来 → 如何单独管理 → 可选工具比较 → 确定性现金流/长期收益空间 → 风险与选择方法 → 行动清单。

- 个税、调仓、止盈、财报、黄金等按年循环的选题，先找同选题上一期。
- 教育金、养老、保险等先讲需求和认知地图，再讲工具。
- 涉及分期领取时，把“一笔一笔现金流”画成时间轴或流程图。

## 三、常用内容积木

这些是可跨期复用的逻辑模块。使用前仍需检索最近版本并核对页码、数据和口径。

- **收益来源**：盈利增长、股息收益、估值变化。
- **市场涨跌三因素**：基本面、资金面、情绪面。
- **牛市阶段特征**：估值修复、盈利变化、增量资金及情绪升温。
- **利率影响**：利率像资产价格的“地心引力”；债券看久期，股票看估值，汇率看利差与资金流向。
- **止盈方法**：高估止盈、目标收益止盈、再平衡；说明适用条件而非只列名称。
- **分散配置与再平衡**：不同资产相关性、再平衡来源、失效场景。
- **固收+工具比较**：收益来源、波动、回撤、流动性、持有期限和适用资金。
- **星级与估值表**：当前星级/估值、在哪里查询、如何用于低估买入和高估止盈。
- **风险与行动**：短期变量难预测，先确定策略；跌出机会买入，涨出机会卖出，其他时间耐心等待。

## 四、单页写法

每页按以下顺序组织：

1. **页标题**：一句短问句或结论句，不写论文式长标题。
2. **核心内容**：1—4条可直接上PPT的短句，或一个表格/一张图。
3. **页面来源**：库别、期数/场次、页码、复用方式、具体更新项。
4. **制作需求**：新图写清时间区间、指标/代码、日频或周频、价格或全收益、对比基准、标注点和截止日期。
5. **气泡显示**：只写标题和图表之外最重要的一句口播判断；这是普通正文制作指令，不是飞书组件。

禁止写“本页将介绍”“我们首先来看”等无信息量串场语。复杂对比超过一眼能读懂的范围时拆页。

## 五、复用标注模板

- 直接复用：`公募直播第463期第5页，直接复用，不用更新。`
- 修改后复用：`公募直播第463期第5页，标题改为……；数据更新至……。`
- 组合复用：`版式复用公募直播第458期第3页，内容参考私募直播第22期第6页。`
- 新做页面：`新做页面：展示……；数据口径……；标注……。`

不能只写“参考历史PPT”或“数据待更新”。引用历史页后，截图紧跟页面说明，caption写清库别、期数/场次、页码和复用方式。

## 六、数据与时效

- 同组走势图统一起止日期、频率、复权/全收益口径、基准和截止日期。
- 结论依赖新数据时，页标题先写“待根据数据调整”，数据更新后再改为确定性结论。
- 估值、星级、小程序、组合日报/季报等时点截图默认直播前更新。
- 内容素材库里“含时点数据”的卡片只代表当时状态；按日期取最新并至少交叉验证两条来源。
- 传播性数字优先使用可核实的保守口径，原素材数字作为红字待复核项。

## 七、口径红线

- 对观众使用“投资者”，不用“散户”。
- 不使用“稳赚、必涨、保本、高收益”等绝对化表述。
- 高净值内容讲策略和方法，不泄露不应公开的具体组合信息。
- 香港保险只在“已有资金在海外”的前提下讨论，不引导资金出海。
- 稳健保等主体必须准确表述为保险代理销售/服务平台，不写成保险产品。
- 正式转化素材缺失时，交由渠道或业务团队补充，不自行编造产品卖点。
- 数据、监管规则、产品状态和活动信息均按直播日期复核。

## 八、交付前自检

- 能否用一句话说清本期结论。
- 是否形成问题、判断、证据、行动闭环。
- 是否选了2—3期最相近的已定稿大纲作为风格样本。
- 是否实际检索三个历史PPT库并打开候选页。
- 每页是否只有一个信息任务，且来源和更新项清楚。
- 所有复用页是否附截图，所有新图需求是否可直接执行。
- 是否只保留当前有效版本，删除页未进入主要思路和总结。
- 是否回答投资者现在具体怎么办，并落到星级/估值和投资纪律。
