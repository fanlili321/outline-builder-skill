# 最近30期已定稿大纲风格基准

样本：第445—474期连续30期，以已确认或标题已确认版本为准，排除弃用稿、AI解析稿和同期重复待确认稿。

本文件的首要用途是**模仿已定稿大纲的真实风格，提高初稿一次通过率**。样本统计只用于识别稳定习惯，不得把频次、页数或模块变成机械配额。每次起草时，先从30期中选择与本期题材最接近的2—3期作为风格样本，重点模仿其逻辑顺序、页标题、单页信息密度、复用标注和口播语气；不要把30期内容平均化成一套万能模板。

## 已定稿大纲的核心风格

- **像讲课，不像写文章**：沿着观众会问的问题逐步展开，先建立背景和概念，再用数据、对比或案例得出判断，最后回答怎么做。
- **页标题就是口播路标**：标题短、口语化，常用明确问句或结论句，如“是什么”“为什么”“该如何投资”“有哪些风险”；避免论文式长标题和抽象名词堆叠。
- **一页一个意思**：一页只讲一个定义、原因、对比、案例或动作。复杂主题拆成连续小页，同组标题保持同一种句式。
- **正文少而具体**：只写上PPT或钉大口播真正需要的信息。短句、数字、对比维度优先，不写大段解释，不用营销腔。
- **先摆事实，再下结论**：走势图、表格、规则、案例是依据；气泡用一句话把依据翻译成观众能带走的判断。
- **复用说明是制作指令**：写清哪一期哪一页、直接还是修改复用、具体改什么；不要用“参考历史页面”这种无法执行的话。
- **待办写到可交接**：红字不是模糊提醒，而是数据、图片、口径、日期和样式的明确任务。
- **结尾一定落地**：根据本期内容给出具体投资动作、查询入口、适用人群或风险提醒；不空喊原则，也不强行推产品。

## 样本信号

- 30/30期引用历史页面或历史素材；历史检索和页面复用是默认动作，不是可选项。
- 27/30期包含数据、走势图、估值图或截图更新要求；初稿必须同步形成数据更新清单。
- 22/30期在确认过程中出现新增或调整页；初稿应先搭最短闭环，给反馈留空间。
- 20/30期使用“气泡显示”；气泡适合承载一页最重要的口播结论，不用于重复标题。
- 12/30期有Q&A；Q&A按观众真实疑问选配，不是每期固定模块。
- 9/30期留有V1/V2/V3痕迹；后续处理必须先确认当前有效版本，废弃版本不得进入总结和文案。
- 每期都有图片和表格；图片数量中位数约20张，但多版本会抬高统计，不能据此机械规定页数。

## 初稿生成顺序

1. 先在最近30期中选择题材、叙事方式最接近的2—3期已定稿大纲，提取其目录层级、标题句式、单页密度和收尾方式，作为本期风格标尺。
2. 确认本期观众要解决的核心问题，用一句话写出本期结论。
3. 从下方对应模板搭出最短逻辑闭环，再决定页面，不先堆素材。
4. 检索历史PPT：同选题上一期 > 相同品种/方法 > 最近1—2期通用页 > 私募及对外演讲中的成熟表达。
5. 打开候选PPT逐页核对，给每页标记：直接复用、修改后复用、组合复用或新做。
6. 把历史页截图放在初稿对应位置，同时列出数据和文字更新项。
7. 逐页与风格样本对照：标题是否像已定稿大纲、正文是否过长、是否一页多义、制作指令是否可执行。
8. 最后补行动页、总结页和必要的Q&A，形成“问题—判断—证据—行动”闭环。

## 风格对齐方法

起草前，对选中的2—3期样本制作一份内部对照，不展示给用户：

- **开场方式**：是用最新事实、用户痛点、概念定义还是案例切入。
- **目录颗粒度**：大纲分几部分，每部分承担什么任务，是否需要过渡页。
- **标题句式**：问句与结论句的比例，同组页面如何重复句式形成节奏。
- **单页密度**：标题下通常有几条短句、一个图还是一个表，是否需要气泡。
- **复用写法**：来源、页码、更新项和截图如何排列。
- **收尾方式**：如何从判断过渡到投资动作、工具入口或风险提醒。

输出初稿后再反向检查：如果拿掉期数和主题，本期稿件的语言、密度和制作指令是否仍像最近已定稿的大纲；不像就先调整风格再交付。

## 五类常用结构

### 指数或品种价值分析

为什么现在讲 → 是什么/规则 → 与相近品种的区别 → 行业及成分股 → 长期表现与波动 → 估值 → 对应基金 → 风险 → 如何投资。

- 基本信息、行业分布、成分股、长期走势、估值、基金清单是高复用模块。
- 不要只讲“好不好”，必须回答“适合谁、当前什么估值、怎么买、有什么风险”。
- 同类指数较多时，先做一页对比，再讲本期主角，避免逐个平铺。

### 市场热点与波动应对

发生了什么 → 为什么发生 → 与历史阶段比较 → 当前处于什么位置 → 后续可能怎样 → 投资者怎么办。

- 开头用最新市场事实建立紧迫性，但不把整期做成新闻复述。
- 原因控制在最关键的2—3个；每个原因至少有一张数据或案例页支撑。
- 行动建议按不同资金状态拆分，例如增量/存量、低估/正常/高估、新手/有经验者。
- 热点型初稿优先控制在15—20页；第二个历史案例或宏观佐证不能推进结论时就删。

### 定期更新型选题

披露/规则是什么 → 为什么值得看 → 本次数据总览 → 按宽基/策略/行业拆解 → 与上期比较 → 结论和投资影响。

- 优先复用上一轮同选题PPT，只更新数据、结论和新增品种。
- 旧页上的定性标题必须等新数据后重判，不能把“景气/复苏/低迷”等旧结论直接沿用。
- 同一批图统一时间区间、频率、全收益/价格口径、基准和截止日期。

### 方法、工具或组合复盘

用户痛点 → 方法/工具是什么 → 判断指标 → 历史数据验证 → 操作步骤 → 适用人群与限制 → 常见疑问。

- 功能页必须写清“在哪里看、多久更新、怎么操作”，不能只解释原理。
- 案例用来证明方法，不要让历史复盘喧宾夺主。
- 操作路径尽量压成2—3步；入口截图、二维码或小程序页面放在对应步骤旁。

### 规划与财商教育类

目标和需求 → 钱从哪里来 → 如何单独管理 → 可选工具比较 → 确定性现金流/长期收益空间 → 风险与选择方法。

- 先按人生阶段或资金用途分层，再讲产品，避免一上来推工具。
- 对保险、基金等方案用同一组维度比较：使用时间、现金流确定性、收益空间、波动和流动性。
- 涉及分期领取时，把“一笔一笔现金流”做成直观时间轴或流程图。

## 单页写法

- 页标题优先写成结论句或明确问句；同一组页面保持句式一致。
- 一页只承担一个信息任务：定义、原因、对比、案例、方法或行动，不混装多个结论。
- 页面说明按“核心结论 → 图表/截图内容 → 来源与更新项 → 气泡口播”排列。
- 气泡只写标题和图表之外的关键判断，通常一句，优先说明适用条件、限制或行动。
- 过渡页只在内容确有两大部分或三种策略时使用；短大纲不为形式硬加过渡页。
- 对比页统一维度，表格列不超过观众能快速扫读的范围；复杂细节拆页。
- 正文默认使用能直接放进PPT的短句，不写“本页将介绍”“我们首先来看”等串场套话。
- 同一结论如果能用一张历史页截图说明，就不要再写一段重复解释；文字负责指出看什么、改什么和结论是什么。

## 历史页与数据更新

- 引用必须写清库别、期数/场次、页码、复用方式和更新项，并紧跟整页截图。
- “数据待更新”必须继续拆成可执行需求：指标名称、证券/指数代码、起止时间、日/周频、价格或全收益口径、对比基准、标注点、截止日期。
- 优先复用旧页的数据需求和源文件设置，再核对本期是否需要改区间、品种和口径。
- 估值表、星级、小程序、组合日报/季报等时点截图，默认直播前更新，不在初稿中伪装成最新数据。
- 图表结论依赖数据时，标题写“待根据数据调整”，拿到数据后再改成确定性结论。

## 控制返工

- 初稿先保留最短闭环。22/30期后续有新增或调整，说明首稿过满比留出反馈空间更容易返工。
- 出现V1/V2/V3时，只读取并加工标注“以此为准”、位于最前或用户明确指定的版本；旧版仅用于理解修改历史。
- 标记“本页删除”的内容不得进入主要思路、总结页、标题或介绍文案。
- 相同标题连续出现时，检查它们是否分别承担不同证据；若只是重复表达，合并为一页。
- Q&A只收正文未充分回答、且会影响行动的2—5个问题；正文已回答的问题不重复。

## 交付前检查

- 能否用一句话说清本期核心结论。
- 是否形成问题、判断、证据、行动的完整闭环。
- 每一页是否有明确来源；所有复用页是否附截图。
- 所有待更新项是否能直接交给数据同事执行。
- 是否只保留当前有效版本，删除页是否已从成品逻辑中排除。
- 是否在结尾回答“投资者现在具体怎么办”，并与本期主题对应，而不是机械套用同一句话。
- 是否已选取2—3期最相近的已定稿大纲做风格对照，且页标题、短句密度、制作指令和口播语气与样本一致。
