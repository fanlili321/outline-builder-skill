# outline-builder

银行螺丝钉直播大纲制作 skill，供 Claude Code 使用。这是一个私有仓库，是 `outline-builder` skill 的**源代码托管地**——本地生效路径是 `~/.workbuddy/skills/outline-builder/`，每次编辑都会自动 `git commit + push` 到这里，不再需要手动打 zip 备份。

## 这个 skill 做什么

覆盖银行螺丝钉直播大纲从起草到发群复核的全流程。用户提到"大纲""直播大纲"，或要创建/起草/建档/配图/总结页/主要思路/标题/介绍文案，统一用它，不改用同类旧技能。正式 PPT 制作走另一个 skill（`live-ppt-builder`），这里只负责飞书大纲文档。

## 标准流程（8步）

1. 用户给素材 → 同时读用户素材 + 公募/私募/对外演讲三个历史 PPT 库 → 在聊天窗口起草第一版逐页大纲
2. 用户确认 → 复制最新已确认模板建飞书文档，放入固定共享文件夹
3. 用户在文档里改大纲，改完在批注里 `@AI`
4. 读取 `@AI` 插图要求 → 按走势图/设计图分流规范出图并插回文档（只读取执行 `@AI` 任务，不处理批注状态）
5. 用户确认或反馈调整图片，直到确认为止
6. 图片确认后 → 生成并写入：主要思路 + 总结页（3-4句）+ 备选标题（2-3条）+ 介绍文案（4条问句）
7. 用户确认四块文案
8. 用户说 OK → 由"直播小助理"机器人发内容小分队群 `@汤爱学`，核验发送成功即结束

只有用户明确要"先在聊天里总结/提取标题"时，才输出内部核对稿、不写文档。

## 使用前提

- 先读 `references/outline_making_guide.md`（九类选题套路、内容积木库、口径红线）。该文件随 skill 仓库维护，不依赖桌面绝对路径。
- `lark-cli docs` 系列命令已升级到 v2，`SKILL.md` 里 A3/B4 段落的旧命令示例仅作说明，实际操作前用 `lark-cli skills read lark-doc` 读当前权威文档。
- 投顾组合净值等内部数据要从 https://dbms.yhlsd.com/ 查询，走真实登录的浏览器访问（飞书/豆包扫码），不是 `lark-cli apps` 命令（那个身份没有协作者权限）；不再用旧的「螺丝钉数据工具箱」（妙搭 app）入口。登录后有直连 REST API（如 `/api/portfolio-nav?portfolioName=...&beginDate=...&endDate=...&page=1&pageSize=2000`），用浏览器 JS 里 `fetch(..., {credentials:'include'})` 复用已登录会话直接取数据，比等"历史导出"异步任务更快。
- **用户口头说的选题简称 ≠ 工具箱里的"组合名称"字面值，两者是多对一/需要人工指定映射，不能靠猜**（470期教训：用户说"主动优选"，工具箱里同时有"螺丝钉金钉宝主动优选A"和"…C"两个份额，AI 选错成了 A；已确认的映射见下表，遇到列表里没有的简称必须先问用户，不能凭字面相似度自己选）：

  | 用户口头简称 | 工具箱组合名称 |
  |---|---|
  | 主动优选 | 螺丝钉金钉宝主动优选**C** |
  | 中证全指全市场 | 螺丝钉金钉宝全市场指数**C1** |
  | 全球组合 | 螺丝钉金钉宝全球指数C |
  | 指数增强 | 螺丝钉金钉宝指数增强C |
  | 365天 | 螺丝钉银钉宝365天C |
  | 90天 | 螺丝钉银钉宝90天C |
  | 月薪宝 | 螺丝钉银钉宝月薪宝C |

  对比基准优先用工具箱"历史导出"里自带的「对比基准」勾选项（如沪深300/中证800等已内置指数代码），不用另外单独去 Wind 查同名指数拼接。
